# Glossary

## Baseline

The documented state of an application before migration activities begin.

---

## Compatibility Rule

A rule defining whether a source state and target state are compatible.

---

## Migration Capability

A modernization capability supported by the platform.

Examples include:

- Java upgrades
- Spring Boot upgrades
- Dependency modernization

---

## Migration Knowledge

Documented and approved knowledge used to plan, execute and validate migrations.

---

## Migration Knowledge Catalog

The authoritative collection of supported migration knowledge, compatibility rules, migration paths and migration recipes.

---

## Migration Matrix

A representation of supported migration paths derived from compatibility rules.

---

## Migration Path

The sequence of supported transitions required to move from a source state to a target state.

---

## Migration Plan

An ordered set of migration units required to achieve a target state.

---

## Migration Recipe

Reusable transformation knowledge used to perform a modernization activity.

A recipe may contain source-code, dependency, configuration or build transformations.

---

## Migration Target

The desired technology state after modernization.

---

## Migration Unit

The smallest independently verifiable modernization activity.

---

## Modernization Assessment

The process used to evaluate the current state of an application before migration planning.

---

## Readiness Assessment

The evaluation of whether sufficient evidence exists to begin migration planning and execution.

---

## Remediation Pattern

A documented solution to a migration problem.

Approved remediation patterns may become migration recipes.

---

## Supported Capability

A migration capability officially supported by the platform.

---

## Validation Evidence

Objective evidence generated during validation activities.

Examples include:

- Build results
- Test results
- Coverage reports

---

## Validation Gate

A checkpoint that must be satisfied before migration execution can continue.
