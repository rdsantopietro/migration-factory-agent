# Product Roadmap

## Purpose

Define the planned evolution of Migration Factory Agent from a Java modernization MVP into a scalable modernization platform powered by reusable migration knowledge.

---

# Phase 1 - MVP Foundation

## Objective

Establish the core modernization workflow for Java applications.

### Capabilities

- Repository assessment
- Migration planning
- Migration execution
- Migration validation
- Migration reporting

### Technologies

- Java
- Spring Framework
- Spring Boot
- Maven
- Gradle

### Knowledge Sources

- OpenRewrite recipes
- Compatibility rules

---

# Phase 2 - Knowledge Expansion

## Objective

Build an internal migration knowledge repository.

### Capabilities

- Custom recipe repository
- Recipe governance
- Approved remediation patterns
- Knowledge catalog expansion

### Outcomes

- Reusable migration knowledge
- Reduced manual effort
- Increased automation coverage

---

# Phase 3 - Intelligent Remediation

## Objective

Assist engineers when existing recipes cannot resolve a migration scenario.

### Capabilities

- Unsupported scenario detection
- Remediation recommendations
- Candidate recipe generation

### Outcomes

- Faster issue resolution
- Continuous knowledge acquisition

---

# Phase 4 - SCM Integration

## Objective

Integrate modernization workflows with source control platforms.

### Capabilities

- GitHub integration
- GitLab integration
- Pull Request generation
- Review workflows

---

# Phase 5 - Portfolio Modernization

## Objective

Modernize multiple repositories at scale.

### Capabilities

- Portfolio assessment
- Portfolio planning
- Portfolio reporting

---

# Phase 6 - Ecosystem Expansion

## Objective

Extend modernization support beyond Java.

### Candidate Technologies

- Kotlin
- C#
- JavaScript
- TypeScript
- Python
- .NET
- Node.js
